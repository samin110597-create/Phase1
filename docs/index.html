Backtest truth

Historical tests remain visible exactly as they are. A forecast can be displayed while validation is pending, but a failed backtest is never rewritten as a pass.

113-stock ranked-candidate holdout

Broad historical test for the few-best-names objective: 113 liquid stocks, historical candidate pools, market/sector/cross-asset features, then model ranking. The final evidence column tells you whether a direction/horizon actually passed the stored validation gate.

Prospective forward validation

The forward logger records fixed intraday forecasts before outcomes are known, then scores matured 1/5/10-session outcomes later.

How the target price is calculated

Central target = current price × [1 + (P(up) − P(down)) × daily ATR% × √horizon]. Projected range = current price ± one horizon-scaled daily ATR. This makes the dollar target auditable and tied to both model probability and current volatility instead of inventing a price.

Truth rule
A numeric forecast is a model output, not a guarantee. MODEL FORECAST means the engine produced a probability and target. VALIDATED MODEL FORECAST is reserved for a rule that has passed the stored validation gate.
