This version is intentionally explicit about freshness: the scanner uses adjusted 1-day OHLCV bars, not live ticks. The scheduled workflow runs after the U.S. close. “Institutional” is an evidence-based proxy from price/volume, relative strength, OBV, trend, breakout quality and liquidity—not private order flow. A true probability percentage would require historical out-of-sample calibration; the dashboard therefore shows Confluence + Confidence separately.
