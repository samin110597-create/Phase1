Known limitations
Current-survivor universes create survivorship bias. Current sector membership is used historically in the ranked model. GitHub Pages is near-live, not streaming. Research estimates are not guarantees.
Research dashboard only. “Research estimate” means the model generated a probability-like estimate; “strict validated” means the relevant frozen rule passed the untouched holdout. Those are intentionally different labels.
